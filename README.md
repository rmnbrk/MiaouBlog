# MiaouBlog



## Guide d'installation

### Avec Wamp
1. Cloner le projet dans "C:\wamp64\www\"
2. Lancer Wamp
3. Rendez-vous sur la page PhpMyAdmin ("localhost/phpmyadmin")
    - Créer une base de données appelée "miaou_blog" avec comme paramètre "utf8mb4_general_ci"
    - Aller dans importer et sélectionner le fichier "BDD/miaou_blog.sql" (Laisser les paramètres par défaut) puis cliquez sur "importer";
4. Pour accéder au site taper dans la barre d'adresse l'url : "localhost/miaoublog/index.php"

### Pour accéder au compte Admin
1. Aller dans la page de connexion et renseigner les infos suivantes:
    - pseudo: Admin
    - mot de passe: admin69IUT;
2. Vous avez désormais à la modification des catégories !
